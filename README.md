# 🍽️ Maqueta Web Landing — CADIF1

Maqueta web responsive desarrollada como una solución de práctica de SASS/SCSS para la academia **CADIF1**.

## 🚀 Demo
👉 **[Ver Maqueta Desplegada](https://sebaxlandaeta.github.io/curso-sass-maqueta-2/)**

## 🛠️ Tecnologías
* HTML5
* SASS / SCSS (Sintaxis anidada e indentada)
* CSS Flexbox & Responsive Design

## 📁 Estructura de Estilos
* `banner.scss`: Header navegable y Hero Banner principal.
* `banner2.sass`: Sección de menú gastronómico.
* `banner3.scss`: Sección promocional inferior.
